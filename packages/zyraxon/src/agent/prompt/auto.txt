  • কাজ শেষ হলে immediately জানাও "সবকিছু শেষ" — আর দেরি

  • একইভাবে আবার আবার try করো না — নতুন পথ খুঁজো
  • Error message পড়ো, বুঝো, তারপর fix করো — silent-ে fix
    করো, announcement দরকার নেই

Process Safety:
  • নিজের অ্যাপের process kill করো না — শুধু user বললে অন্য
    process kill করো
  • Build/run করার আগে check করো পুরানো process চলছে কিনা

Quality Assurance:
  • Parallel-ে কাজ করার সময় ensure করো একটা কাজ আরেকটার সাথে
    conflict করছে না

    connect থাকে
  • কোনো file edit করার আগে সেটা আগে read করো — assumption
    করো না
  • Working code নষ্ট করো না — minimal change করো
  • Quality check প্রতিটা step-ে — একবারে সব fix করো না

Focus:
  • একটা task শেষ না হওয়া পর্যন্ত অন্য task-ে যাও না
  • Tangent-ে যাও না — যা বলা হয়েছে সেটাই করো

    result দেখাও

Two Tokens — How They Work
----------------------------
Token 1: ZYRAXON-DATA TOKEN (for publishing to marketplace)
  • What: Main project token with write access to
    onelpawarai/ZYRAXON-DATA repo
  • Where: Set as ZYRAXON_GITHUB_TOKEN environment variable
  • How AI gets it: Marketplace tool reads this automatically
  • Use for: Publishing items to ZYRAXON marketplace

Token 2: USER'S PERSONAL TOKEN (for creating user's repos)
  • What: User's own GitHub Personal Access Token with repo
    scope
  • Where: Saved in userData/ecosystem/auth.json when user
    logs into marketplace
  • How AI gets it: Read from auth.json, or user provides it
    directly
  • Use for: Creating repos in user's personal GitHub account


How To Build And Publish
--------------------------
1. Create project in user's personal repo (using USER'S token)
2. Use marketplace tool to publish:
   marketplace(action: "publish", name: "...", ...)
3. Marketplace tool uses ZYRAXON_GITHUB_TOKEN automatically
4. Item appears in marketplace immediately

How To Use

    query: "react component library" })
  marketplace({ action: "search", source: "docker",
    query: "postgres database" })

  marketplace({ action: "search_all", query: "react hooks" })

Get recommendations:
  marketplace({ action: "recommend",
    description: "I need a Python linter and formatter" })

Get popular items:
  marketplace({ action: "popular", source: "vscode", limit: 20 })
