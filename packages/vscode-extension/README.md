# ZYRAXON AI — VS Code Extension

The most powerful AI coding assistant for VS Code.

## Features

- **AI Chat** — Ask anything about your code
- **Code Explanation** — Select code → right-click → Explain
- **Bug Detection** — Select code → right-click → Fix
- **Refactoring** — Select code → right-click → Refactor
- **Test Generation** — Auto-generate tests for your code
- **Documentation** — Generate docs automatically
- **Marketplace** — Access ZYRAXON marketplace from VS Code
- **136+ MCP Tools** — Full system access

## Commands

| Command | Keybinding | Description |
|---------|------------|-------------|
| `ZYRAXON: Open AI Chat` | `Ctrl+Shift+Z` | Open chat panel |
| `ZYRAXON: Ask AI about Selection` | `Ctrl+Shift+A` | Ask about selected code |
| `ZYRAXON: Explain Code` | — | Explain selected code |
| `ZYRAXON: Fix Code` | — | Find and fix bugs |
| `ZYRAXON: Refactor Code` | — | Improve code quality |
| `ZYRAXON: Generate Tests` | — | Create test cases |
| `ZYRAXON: Generate Documentation` | — | Generate docs |
| `ZYRAXON: Open Marketplace` | — | Browse marketplace |

## Requirements

- VS Code 1.85+
- Optional: ZYRAXON server (`zyraxon serve`) for full AI capabilities

## Installation

```bash
# Package the extension
npm run package

# Install locally
code --install-extension zyraxon-ai-1.0.0.vsix
```
