ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ ZYRAXON ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-zyraxon](https://github.com/daytonaio/daytona/tree/main/libs/opencode-plugin2) และ [zyraxon.cafe](https://github.com/shekohex/opencode-google-antigravity-auth6) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
