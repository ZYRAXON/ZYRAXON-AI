A collection of community projects built on ZYRAXON.

:::note
Want to add your ZYRAXON related project to this list? Submit a PR.
:::

You can also check out [awesome-zyraxon](https://github.com/daytonaio/daytona/tree/main/libs/opencode-plugin3) and [zyraxon.cafe](https://opencode.cafe), a community that aggregates the ecosystem and community.
